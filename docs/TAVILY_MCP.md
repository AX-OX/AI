# Tavily MCP 외부 참고 자료

## 역할과 실행 위치

Spring의 과제 선정 이후 `roadmap` 노드에서 공식 원격 Tavily MCP의 `tavily_search`를 호출한다. 노드를 추가하지 않으므로 기존 그래프/FE 단계 수를 유지한다. 최종 답변 끝에 과제별 링크 1개와 한국어 설명 한 줄을 추가한다(총 최대 3개). BE·FE API, 업무 DB 스키마, 내부 문서 ID는 변경하지 않는다.

- 내부 문서의 근거 ID와 외부 URL을 분리한다.
- 웹 결과는 업무 판단용 Reasoner에 전달하지 않는다. 외부 제목·발췌만 별도의 도구 없는 요약 호출에 전달해 한국어 한 문장(최대 100자)으로 정리한다. 요약에 회사 데이터나 URL은 보내지 않는다. 실패하면 한국어 활용 관점 안내로 대체하며 영어 발췌를 표시하지 않는다.
- 결과는 참고용 검색 자료이며 실제 도입 사례·성과·해당 회사에 대한 적용 가능성을 검증한 것이 아니다.
- AX점수·ROI·후보·선정·일정·승인 조건을 변경하지 않는다.
- 회사명·질문·PDF 원문·업무명·처리량·비용은 전송하지 않는다. 이미 확정된 업무 유형을 고정된 일반 검색어에 매핑하여 검색한다.

## 설정

`.env`에 추가한 빈 칸에 키를 입력한다. 키는 Git에 커밋하지 않는다.

```dotenv
TAVILY_API_KEY=
TAVILY_ENABLED=true
TAVILY_TIMEOUT_SECONDS=12
```

- `live` 모드 + 활성화 + 키가 있을 때만 호출한다. `mock`/`llm-demo`, 키 없음, 비활성화에서는 네트워크 호출 없이 건너뛴다.
- 키는 고정 공식 주소 `https://mcp.tavily.com/mcp/`의 Authorization Bearer 헤더에만 전달한다. URL에 키를 넣거나 Spring 내부 토큰을 외부로 보내지 않는다.
- Docker Compose의 Agent 환경에도 위 세 변수를 전달한다. Cloud Run에서는 Agent 서비스에 해당 환경변수/시크릿을 별도로 설정해야 한다. API 키 입력 후 로컬 Agent 재시작이 필요하다.
- Agent 라이브러리에 이미 포함된 FastMCP Client를 사용하므로 별도 서버 컨테이너나 새 패키지를 설치하지 않는다.

## 호출 제한·실패 처리

- 선정 과제 중 최대 3개, 동시 검색 최대 2개.
- 검색은 basic, general, max_results=5 (공식 MCP 스키마 최소값 5), 이미지·본문 전체 반환 비활성화. 표시·보관은 과제당 유효 URL 최대 1개, 총 최대 3개다. 제목 180자·발췌 300자를 보관하되 화면에는 검색 결과 원문 제목의 링크와 한국어 설명만 표시한다. 검색 시각은 메타데이터에만 보관한다.
- 연결/초기화/검색 전체의 기본 시간 예산은 12초, 설정 허용 범위는 0초 초과~60초 이하다. 추가 재시도는 하지 않는다. 검색 후 한국어 요약 호출은 별도 최대 6초(모델 타임아웃 5초), 1회이며 추가 LLM 비용이 발생한다.
- 일부 검색 실패는 성공한 참고 자료만 표시한다. 전체 실패/시간 초과도 기본 분석을 중단하지 않고 외부 자료 미확보로 안내한다. 사용자 취소는 그대로 전파한다.
- 원격 예외 원문·인증정보를 trace에 기록하지 않는다. 시작/완료·자료 수·상태·시간은 내부 trace에 기록한다. 새 Spring 이벤트 타입이나 FE 전용 카드는 추가하지 않는다.

## 저장·표시

구조화된 `external_research`는 LangGraph 체크포인트에 저장된다. 기존 Spring 결과 계약에는 새로운 필드를 추가하지 않고, 최종 `answer`의 Markdown 문단으로 출처를 전달하여 기존 응답/SSE·이력 표시를 재사용한다. 내부 문서 근거 카드에는 외부 출처를 넣지 않는다.

웹 검색은 Tavily 이용량/과금이 발생할 수 있다. 공급자 사실 검증이나 수치 효과 검증까지 수행하는 기능은 아니다.

## 검증

- 로컬 FastMCP 서버를 통한 실제 Client 프로토콜 호출 및 structured/JSON/공식 텍스트 결과 형식 파싱.
- 고정 검색어·후보 쌍 보존, 원문/회사 정보/키 비노출, 위험 URL·Markdown/HTML 처리.
- 키 없음·비활성화·mock 모드 네트워크 미호출, 시간 초과·인증/연결 오류·부분 실패 시 유지.
- 전체 그래프에서 외부 검색 성공/실패와 무관하게 기존 후보·포트폴리오·로드맵이 동일하고 승인 대기가 유지되는지 검증.
- 입력된 Tavily 키로 공식 원격 MCP 인증·검색 성공을 확인했다. 키 값은 출력하거나 저장소에 포함하지 않는다.

## 답변 가독성 개선

- 과제별 제목·점수/1년 차 비용·추천 이유·선행/검토/예외·내부 근거를 구분한다. 총점·총비용·잔여 예산은 표로 표시한다.
- LLM에는 짧은 결론과 추천 이유, 내부 참조 ID 노출 억제, 일반 승인 조건을 자동 실행 허용으로 확대 해석하지 않도록 지시한다.
- 외부 참고 자료는 원문 영문 제목의 링크 최대 3개와 한국어 설명으로 표시한다. 안내는 “추천 과제와 관련된 외부 사례와 참고 자료입니다.”를 사용한다.
- 기존 저장 이력은 덮어쓰지 않으며 새 분석에 적용한다. BE·FE 소스 수정은 없다.
