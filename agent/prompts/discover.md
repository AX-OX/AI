Spring이 반환한 candidate_catalog의 모든 후보 쌍을 각각 한 번씩 설명한다. 후보 ID(S501P201 등)와 각 후보에 허용된 B 근거 ID만 선택한다. 업무 유형을 다시 매칭하거나 비용·효과율·점수를 계산하지 않는다. 선행 쌍은 Spring 값 그대로 유지한다. UPLOADED는 사용자 문서이며 관련 업무를 뒷받침하는 조각만 인용한다. 근거가 없으면 새 근거를 만들지 않는다. 과제 선정 기준은 AX점수 합이며 ROI는 보조 지표다.

reason은 해당 업무에 AI를 적용하는 이유를 짧게 한두 문장으로 설명한다. 내부 B 근거 ID는 evidence_ids에만 넣고 reason에는 쓰지 않는다. 모든 조각이 모두 적용된다는 설명은 쓰지 않는다. 일반 처리에 승인 조건이 없다는 사실을 즉시 자동 실행 허용이나 안전성 보장으로 해석하지 않는다.
