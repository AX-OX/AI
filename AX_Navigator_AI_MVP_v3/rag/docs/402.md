# 기획 업무 매뉴얼

## 문서 범위

가온비즈정밀 주식회사 (가상), company_id=1. 문서 ID 402, 버전 v3. 모든 인물·연락처·업무수치·사례는 가상이며 data_source=ASSUMED다. 실제 도입 효과로 주장하지 않는다.

## 가상 담당자

이름 가상담당자B, 이메일 demo.102@gaon.example, 연락처 010-0000-0002. 외부 답변은 이름·이메일·전화번호를 마스킹하고 문서 ID·절을 인용한다.

## 204 주간 업무 보고 취합

process_id=204. 목적: 부서 보고의 누락과 중복을 줄이고 표준 보고서를 작성한다.
절차:
1. 보고 요청
2. 부서별 보고 수집
3. 누락·중복 확인
4. 주간 보고 초안 작성
5. 기획 담당자 검토·승인
requires_approval=true. 사람의 최종 검토·승인 후 진행한다.
예외 규칙: 대외 공개 수치와 경영진 의사결정은 사람이 확인한다.

## 205 시장·경쟁사 동향 리포트 작성

process_id=205. 목적: 출처가 있는 시장 동향 초안을 작성하고 사실을 검증한다.
절차:
1. 허용 자료 수집
2. 출처·날짜 확인
3. 주제별 요약
4. 리포트 초안 작성
5. 기획 담당자 사실 검토·승인
requires_approval=true. 사람의 최종 검토·승인 후 진행한다.
예외 규칙: 미확인 수치와 출처 없는 주장은 제외한다. 현재 연결 시스템에 API가 없어 수동 수집이 필요하다.

## 206 회의록 작성·액션 아이템 정리

process_id=206. 목적: 회의 내용을 요약하고 담당자와 기한을 명확히 정리한다.
절차:
1. 녹취 동의 확인
2. 회의 자료 수집
3. 발언·결정 사항 요약
4. 담당자·기한 정리
5. 회의 주관자 검토·승인
requires_approval=true. 사람의 최종 검토·승인 후 진행한다.
예외 규칙: 동의 없는 녹취와 민감 인사 정보는 처리하지 않는다. 담당자·기한은 주관자가 확정한다.
