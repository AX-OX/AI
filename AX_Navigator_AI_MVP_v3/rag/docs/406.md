# AI 활용 현황

## 문서 범위

가온비즈정밀 주식회사 (가상), company_id=1. 문서 ID 406, 버전 v3. 모든 인물·연락처·업무수치·사례는 가상이며 data_source=ASSUMED다. 실제 도입 효과로 주장하지 않는다.

## 현재 활용

문서 초안 작성과 티켓 분류를 소규모 시험 중이라는 가상 시나리오다. 운영 자동 실행·효과 측정은 아직 없다. AI 사용 지침은 초안이고 정기 교육·평가 체계가 부족하다.

## 역량과 거버넌스

개발팀은 코드 저장소·이슈 트래커 API를 사용할 수 있다. 승인된 문서 버전·개인정보 마스킹·사람 검토를 우선한다. 가상 성숙도 레이블은 기업 진단용이며 과제 AX점수와 별개다.
