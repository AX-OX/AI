# 보안·데이터 처리 정책

## 문서 범위

가온비즈정밀 주식회사 (가상), company_id=1. 문서 ID 404, 버전 v3. 모든 인물·연락처·업무수치·사례는 가상이며 data_source=ASSUMED다. 실제 도입 효과로 주장하지 않는다.

## 개인정보 처리

가상 연락처도 마스킹하여 제공한다. 원문 인용 시 이메일·전화번호·담당자 이름을 치환한다. access_level은 민감도 표시용이며 역할 권한은 없다. 시크릿·고객 데이터는 입력하지 않는다.

## 사람의 최종 판단

203 인사평가 등급 산정은 AI 자동 실행에서 제외한다. 208 코드 리뷰는 AI가 의견 초안을 작성하되 개발자가 최종 검토·승인한다. 코드 병합·배포를 자동 실행하지 않는다.

## 요청자 본인 승인

로드맵 및 프로젝트는 요청자 602의 명시적 승인 후 등록한다. requires_approval은 개별 업무의 사람 검토 조건이고 서비스의 로드맵 승인과 별개다. 승인 전에는 WAITING_APPROVAL로 멈춘다.
