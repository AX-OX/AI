# 인사 업무 매뉴얼

## 문서 범위

가온비즈정밀 주식회사 (가상), company_id=1. 문서 ID 401, 버전 v3. 모든 인물·연락처·업무수치·사례는 가상이며 data_source=ASSUMED다. 실제 도입 효과로 주장하지 않는다.

## 가상 담당자

이름 가상담당자A, 이메일 demo.101@gaon.example, 연락처 010-0000-0001. 외부 답변은 이름·이메일·전화번호를 마스킹하고 문서 ID·절을 인용한다.

## 201 사내 규정 문의 응답

process_id=201. 목적: 최신 인사 규정의 조항을 찾아 반복 문의에 근거와 함께 응답한다.
절차:
1. 문의 접수
2. 개인정보 제거
3. 최신 규정 검색
4. 근거 조항 확인
5. 답변 초안 전달
requires_approval=false. 정해진 예외는 담당자에게 이관한다.
예외 규칙: 개인별 급여·징계·법률 해석 문의는 인사 담당자에게 이관한다.

## 202 신규 입사자 온보딩 안내

process_id=202. 목적: 입사 준비물과 필수 교육 일정을 일관되게 안내한다.
절차:
1. 입사 일정 확인
2. 직무별 체크리스트 조회
3. 안내문 초안 작성
4. 입사자 확인
5. 미완료 항목 알림
requires_approval=false. 정해진 예외는 담당자에게 이관한다.
예외 규칙: 계정 권한 발급과 근로계약 확정은 담당자가 별도 처리한다.

## 203 인사평가 등급 산정

process_id=203. 목적: 인사위원회가 근거 자료를 검토하여 직원의 최종 평가 등급을 결정한다.
절차:
1. 평가 자료 취합
2. 근거 누락 확인
3. 인사위원회 검토
4. 위원회 최종 등급 결정
5. 결과 통지
requires_approval=true. 사람의 최종 검토·승인 후 진행한다.
예외 규칙: 사람의 최종 평가 등급 결정은 AI 자동 실행 대상에서 제외한다. 자료 정리와 최종 판단을 구분한다.
