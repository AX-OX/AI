# IT 시스템 명세

## 문서 범위

가온비즈정밀 주식회사 (가상), company_id=1. 문서 ID 405, 버전 v3. 모든 인물·연락처·업무수치·사례는 가상이며 data_source=ASSUMED다. 실제 도입 효과로 주장하지 않는다.

## 시스템과 API

301 인사정보 HRIS: api_available=false, data_access_level=RESTRICTED
302 그룹웨어: api_available=true, data_access_level=RESTRICTED
303 이슈 트래커: api_available=true, data_access_level=RESTRICTED
304 코드 저장소: api_available=true, data_access_level=RESTRICTED
305 사내 위키: api_available=false, data_access_level=RESTRICTED
306 제조 ERP: api_available=false, data_access_level=RESTRICTED

## 업무 연결

## API 판정

201은 API 없는 HRIS·위키만 연결하지만 솔루션 501은 API 불필요이므로 api_ok=true. 205는 위키·ERP에 API가 없고 솔루션 505는 API 필요이므로 api_ok=false. 505의 표준화 .70은 최소 .75보다 낮아 LOW_STANDARDIZATION 경고를 표시한다.
