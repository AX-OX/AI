## 기업 단위 데이터 조회 및 문서 분류
모든 사용자는 자신의 소속 기업(company_id)에 해당하는 업무 데이터와 문서만 조회한다. 검색 시 서버가 인증된 요청자와 company_id 일치를 검사한다. 사용자별 직책에 따른 승인 등급은 두지 않는다.

문서의 PUBLIC/INTERNAL/CONFIDENTIAL 표시는 민감도 및 출력 주의사항을 위한 메타데이터이며, 역할별 접근 허용 목록으로 사용하지 않는다. CONFIDENTIAL 문서를 RAG로 인용할 때는 개인정보 비식별화와 필요 최소한의 발췌를 적용한다. 실제 운영 환경의 정보보호 정책은 별도 설계가 필요하다.

## 개인정보 보호 및 감사 기록
인사 서류·고객 식별자는 모델 입력 전에 가명화하고, 실명·휴대전화·주민등록번호 등은 원문과 출력에 노출하지 않는다. 개인정보 관련 외부 API 전송은 기본 차단한다.

조회와 변경 이력에는 요청자 user_id, 기업 company_id, 시각, 문서 또는 프로젝트 ID, 수행 작업 및 처리 결과를 기록한다. 역할 기반 승인자는 따로 두지 않는다.

## 투자 승인 및 프로젝트 생성
연간 AX 투자 한도는 300,000,000 KRW이며 초년도 구축비와 1년 운영비의 합을 기준으로 검토한다. 가격과 자동화율은 솔루션 카탈로그의 고정된 합성 가정을 사용한다.

로드맵의 후보는 추천 결과일 뿐이다. **요청자 본인이** 로드맵을 명시적으로 승인(또는 거절)하며 승인 전 프로젝트 생성 및 상태 변경은 금지한다. 승인 시 ai_tasks.user_id와 ax_roadmaps.approved_by가 동일한 사용자여야 하고, approval_status=APPROVED인 경우에만 프로젝트를 등록한다.

비용·일정이 변경될 때도 동일 요청자의 별도 확인을 받은 후 변경을 기록한다. Agent는 사용자 승인 없이 DB 변경을 실행하지 않는다.

## 채용 AI 공정성과 사람 검토
지원서 요약과 직무 관련 객관적 검토 보조만 허용한다. 채용 합격·불합격 자동 결정은 금지하고, 인사 실무자의 별도 최종 검토가 필요하다. 이름·사진·생년월일·성별 등 평가에 불필요한 정보는 모델 입력에서 제외한다.
